## 📌 Project Overview

An interactive component sandbox for engineering and benchmarking accessible UI primitives, fluid micro-interactions, modal dialogs, drawer menus, and design systems.

---

## 🚀 Key Features

- **Component Showcase:** Live testing environment for accordions, modals, tooltips, and sliders.
- **Accessibility Benchmarks:** Full ARIA compliance and focus trap testing across all interactive elements.

## 🚦 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/chilkotiKartik/ui-component-lab.git
cd ui-component-lab
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
